# University Coding LMS & Academic Intelligence Platform

Development vendor-demo monorepo for the University Coding LMS.

## Structure
- `apps/web`: Next.js frontend
- `apps/api`: NestJS backend API
- `workers`: Node.js sandbox/compiler workers
- `packages/*`: Shared internal packages

## Getting Started
1. `npm install`
2. `docker-compose up -d`
3. Configure `.env`
4. `npm run dev`
